# b10 P0：175 子集结论的全量重验报告

日期：2026-09-15 | 数据：HF BTC 14,226 窗口 / ETH 11,245 窗口（全量）
口径：would-enter = elapsed∈[90,150] 且冷门方 ask∈(0.20,0.30]；真订单 =
final_outcome == cand（数据集推断值）；EV = 胜率 − (ask + 0.07·ask·(1−ask))。

## 核心结论：子集偏差实锤，线性过滤空间坍塌

b09 全部分桶研究基于 175 窗口子集（数据集前 16.6h 连续时段，`--limit`
历史遗留）。全量重验结果分三档：

| 子集结论 | 全量结果 | 判定 |
|---|---|---|
| 基线胜率 25.6% / EV -0.013 | BTC 22.2% / EV -0.047；ETH 24.5% / -0.024 | **子集偏乐观** |
| 方向不对称 8 倍（Down/spot↑ 33% vs Up/spot↓ 13.5%） | 四象限 21.0~23.2%，ETH 同样收敛 | **证伪** |
| slope_30 单特征 AUC 0.665 | AUC 0.520（val 段） | **坍塌** |
| depth<0.27 胜率 13.6%（重灾区） | BTC 16.9% vs 保留区 22.8%；ETH 18.3% vs 25.2% | **方向复现、幅度减半** |
| 深跌(ud30≤-0.15) ret60 +0.10~0.12 | ret60 +0.0065；**ret120 +0.0962** | **60s 口径坍塌、120s 口径复现** |
| slope_30≥Q75 过滤胜率 39.4% | 最好单规则 24.3%（+2.6pp vs 基线） | **坍塌** |

## 详细证据

### 1. depth_ratio（唯一通过重验的结构信号）

- 等频 5 分位桶单调：BTC Q1 17.8% → Q5 26.9%；ETH 19.1% → 28.5%
- 0.27 阈值两侧：veto 区胜率 16.9%/18.3%，保留区 22.8%/25.2%
- 误杀低：veto 区只含 7.7%（BTC）/7.3%（ETH）的真单
- **但单独 veto 不转正**：保留区 EV 仍 -0.046（BTC）/-0.022（ETH）；
  veto 区只占 10% 行数、亏损仅略差（-0.053）——减亏量级太小
- 阈值网格（0.20~0.40）无局部最优迹象，单调弱结构

### 2. 单特征分离度（val 段，walk-forward 后）

最佳 AUC 仅 0.552（depth_ratio / cand_ask 并列）。175 子集的
slope_30/ret_30（0.665）是时段巧合产物。**线性可分离度基本不存在。**

### 3. 单规则过滤（阈值=train 分位数，val 验证）

- 最好规则 ret_15≥Q75：val 胜率 24.3%（基线 21.7%），EV -0.023
- 全部 20 条候选规则无一转正；FP 降幅 79~81% 的代价是 recall 只剩 ~22%
- **过滤掉一半假订单容易（任何高阈值都能做到），同时保住真订单做不到**

### 4. elapsed 时间维度

带内 would-enter 胜率 21.5~22.4% 平坦无结构；入场窗 [90,150] 无优化
空间。E5 误杀审计中"早窗真单率 31.4%"是价格混杂效应（早窗含更多
高价行），非可回收信号。

### 5. 深跌反弹的视野依赖（本轮最重要的正发现）

ud_ask_delta_30 分桶（全量 would-enter）：

| 桶 | N | 结算胜率 | ret60 | ret120 |
|---|---|---|---|---|
| ≤-0.15（深跌） | 38,030 | 23.9% | +0.0065 | **+0.0962** |
| -0.15~-0.08 | 35,648 | 23.2% | +0.0015 | +0.0815 |
| -0.02~0.02 | 28,652 | 22.1% | -0.0220 | +0.0369 |
| ≥0.08（被买入） | 12,717 | 20.7% | -0.0532 | -0.0319 |

- 单调方向全量复现（深跌最好、被买入最差）
- **60s 视野下幅度坍塌 15 倍；120s 视野下依然强**——反弹是慢变量
- 但结算胜率仅 23.9% < 盈亏线 26.8%：路径收益的货币化仍卡在
  taker 出场费（四轮已证伪）——**唯一通道是 maker 出场**

## 对计划的影响（按计划 P0 第 4 条执行收缩）

1. **P2 候选清单收缩**：线性单特征/单规则过滤全线降级为"无独立价值"；
   depth<0.27 保留为唯一的 hard veto 候选（低误杀、方向跨币种稳定，
   但只作减亏项不作转正项）
2. **P3 max_vol 下探不受影响**：b07 波动过滤的证据独立于特征坍塌
  （窗口级波动维度 vs tick 级微观结构维度），照计划执行
3. **新增高价值方向**：120s 慢反弹 + maker 出场的组合是出场侧唯一
   未被证伪的路径（taker 止盈已证伪、结算口径 23.9% 不足）——
   maker 方向从"远期候选"提升为 P4 后的第一优先
4. Soft probability 层（规则型胜率查表）维持不上——线性分离度不足，
   查表型模型的输入信号本身已坍塌
