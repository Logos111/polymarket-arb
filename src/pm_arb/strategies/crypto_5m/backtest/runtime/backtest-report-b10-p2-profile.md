soft probability 查表层维持不上。

## E2 单规则过滤（阈值=train 分位数，val 验证）

- BTC：最好规则 val 胜率 24.3%（基线 21.7%），EV -0.023 不转正；20 条规则无一转正。
- ETH：20 条规则中**唯一一条 val EV 转正**：`relative_obi ≥ 1`，
  val N=7165、胜率 28.5%、EV **+0.0131**（FP 降幅 83.6%、recall 20.2%）。
  显著性粗估：胜率差 1.6pp ≈ 3 SE（单规则单币种），但这是 20 条候选中的
  最优（多重比较），且 BTC 上同类规则不进前列——**登记为 P4 rolling
  walk-forward 的待验观察项，不作为候选规则**。

## E4 Hard Negative（score≥2 且输）

- BTC：5,349 笔（假单 12.7%）；ETH：4,213 笔（13.5%）
- 两币一致：hard-neg 与赢家在 cand_ask/depth_ratio 上几乎无差
  （中位逐字相同），只在 relative_obi / score / ret_120 上有弱差
- **解读：评分高的输单不是"缺一个特征"，而是该价位区间的结构性输家
  ——再次指向入场侧无独立修复空间**

## E5 误杀审计（全量行，含非入场行）

| 区块 | BTC 真单率 | ETH 真单率 | 对照入场行 |
|---|---|---|---|
| ask≤0.20（过冷） | 8.7% | 9.0% | 22.3% / 24.3%（全量） |
| ask>0.30（带外） | 38.8% | 39.6% | 同上 |
| 早窗 elapsed<90 | 31.4% | 31.0% | 同上 |
| 晚窗 elapsed>150 | 21.7% | 21.2% | 同上 |

- **带外高价行真单率 38.8%/39.6%**（两币一致）：ask>0.30 的行天然胜率高——
  这是价格带边界效应（越接近 0.30+，越接近热门方），不是可回收信号：
  带内口径的 EV 按各自 ask 盈亏平衡计算，39.6% 不足 0.35+ 的盈亏线。
- 早窗 31.4%/31.0% 已在 P0 排除（带内 elapsed 分桶 21.5~22.4% 平坦，
  31% 是价格混杂效应）。
- **可回收项结论：无**。所有"单独条件误杀但过滤力不强"的区块经口径
  校正后都不含超额真单——误杀回收方向（用户核心问题之三）证伪。

## 综合（P0 + P2 汇总，对计划 P3 的输入）

1. 入场侧线性过滤（单特征/单规则）跨币种全线坍塌：AUC ~0.55、无转正规则
2. depth_ratio 是唯一保留的 hard veto 候选（减亏项，不转正项）
3. 误杀回收无空间；E2 观察项（ETH relative_obi≥1）留待 P4 检验
4. 剩余可做的入场侧杠杆只有**非线性/组合信号**与 **max_vol 下探**（P3）
5. 出场侧 maker 方向（120s 慢反弹货币化）仍是 P4 后第一优先

## 限定

- outcome 为数据集推断值（非链上结算），所有胜率带此限定
- EV 为 taker 持有到结算口径（entry ask + 0.07·ask·(1−ask) 盈亏线），未含滑点
- E5 区块真单率对照的是各自币种入场行全量胜率，区块内均价不同
  （高价带外行 ask 更高），跨区块比较必须用各自盈亏线校正
